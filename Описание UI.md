# Описание UI
# Основной путь
1. Пользователь переходит на экран "Список заявлений" с пустым списком.Нажимает кнопку "Создать заявление".
2. Переходит на экран "Создание заявления".Нажимает на кнопку "Сохранить"/ "Подать заявление".
3. Переходит на экран "Список заявлений" и отображается созданное заявление.
4. При нажатии на значок "глаз" отображается экран "Просмотр заявления".
5. При нажатии на значок "карандаш" отображается экран "Изменение заявления".

# Просмотр списка заявлений
GET /api/v1/requests
| **Элемент** | **Тип элемента** | **Описание** |
| --- | --- | --- |
| Кнопка "Создать заявление" | Кнопка | Переход на форму создания заявления |
| Фильтр по категории | Выпадающий список | Значения справочника берутся из таблицы category в БД. Также есть возможность не применять фильтр, использовав значение "---". Значения: ---, Обучение, Медицина, Спорт, Страхование, Пенсионные взносы, Благотворительность. |
| Фильтр по статусу | Выпадающий список | Значения справочника берутся из таблицы status в БД. Также есть возможность не применять фильтр, использовав значение "---". Значения: ---, Создано, Отправлено партнеру, Отправлено в ФНС, Заполнено, На проверке, Возврат, Исполнено, Отказ. |
| Список заявлений | Таблица | Выводится таблица со столбцами №, статус, сумма и дата создания |
| Значок "Глаз" | Кнопка | При нажатии переход на форму просмотра заявления. Выполняется метод GET /api/v1/requests/{requestId} |
| Значок "Карандаш" | Кнопка | При нажатии переход на форму изменения заявления. Активна только для статуса "Создано". |
| Значок ":" | Кнопка | Раскрывает меню с кнопками: посмотреть, изменить, подать заявление, отменить заявление |
| Пагинация | Навигация | Кнопки "Назад", номера страниц, "Вперед". |
| Уведомление | Message bar | Возникает при успешном создании заявления, доступ запрещен |

# Создание заявления
| **Элемент** | **Тип элемента** | **Описание** |
| --- | --- | --- |
| Категория | Выпадающий список | Выбор категории расходов из таблицы category в БД. Значения: Обучение, Медицина, Спорт, Страхование, Пенсионные взносы, Благотворительность. |
| Компания | Поле выбора с поиском | Поиск и выбор компании-партнера из таблицы partner в БД. Поле с автодополнением. Вводится название, система предлагает варианты. |
| Транзакции | Аккордион с чекбоксами | Разворачивается автоматически после ввода категории и компании. Содержит список доступных транзакций с чекбоксами для выбора. Пользователь может выбрать одну или несколько транзакций. |
| Тип получателя | Выпадающий список | Выбор типа получателя вычета из таблицы typeapplicant в БД. Значения: За себя, Супруг(а), Родитель, Ребенок. |
| Поле ввода | Текстовое поле | Используется для заполнении формы. |
| Паспортные данные | Блок | Группа полей для паспортных данных. |
| Значок "+" | Кнопка | При нажатии добавляет группу полей. Показывается внутри блока "Паспортные данные"/ “Свидетельство о рождении“. |
| Свидетельство о рождении | Блок | Группа полей для свидетельства о рождении. |
| Кнопка "Сохранить" | Кнопка | Сохраняет заявление как черновик в статусе "Создано". Выполняется метод POST /api/v1/requests|
| Кнопка "Подать заявление" | Кнопка | Сохраняет и сразу подает заявление. Заявление переходит в статус "Отправлено партнеру". Выполняется метод POST /api/v1/requests |
| Символ "*" | Текст | Указывает на обязательность элемента. |
| Значок "-" | Кнопка | При нажатии очищает и скрывает поля внутри блока "Паспортные данные"/ "Свидетельство о рождении". |
| Ошибка | Текст | Отображается для каждого поля, которое не прошло валидацию. С описанием ошибки |

## Описание валидации полей
| **Поле** | **Обязательность** | **Тип данных** | **Ограничения** |
| --- | --- | --- | --- |
| Категория | Да | Поле выбора | Одно значение из справочника |
| Компания | Да | Поле выбора | Запись должна быть активной (isActive = 1) в таблице partner |
| Транзакции | Да | Поле множественного выбора | Должна быть выбрана хотя бы одна транзакция из списка транзакции, которые соответствует категории и компании. |
| Тип получателя | Да | Поле выбора | Только одно значение из справочника |
| Фамилия | Да | Строка | От 1 до 50 символов. Только буквы, пробелы и дефис |
| Имя | Да | Строка | От 1 до 50 символов. Только буквы |
| Отчество | Нет | Строка | От 1 до 50 символов. Только буквы |
| Дата рождения | Да | Дата | Формат: DD.MM.YYYY Не может быть в будущем и не ранее 01.01.1926 |
| ИНН | Нет | Целое число | 10 или 12 цифр |
| Серия паспорта | Условно да, если добавлены паспортные данные | Целое число | 4 цифры |
| Номер паспорта | Условно да, если добавлены паспортные данные | Целое число | 6 цифр |
| Код подразделения | Условно да, если добавлены паспортные данные | Строка | 7 символов Формат: XXX-XXX где X - цифра |
| Кем выдан | Условно да, если добавлены паспортные данные | Строка | От 1 до 255 символов |
| Дата выдачи паспорта | Условно да, если добавлены паспортные данные | Дата | Формат: DD.MM.YYYY Не может быть в будущем и не ранее 01.01.1926 |
| Серия свидетельства | Условно да, если добавлено свидетельство о рождении | Строка | 4 символа |
| Номер свидетельства | Условно да, если добавлено свидетельство о рождении | Целое число | 6 цифр |
| Кем выдано | Условно да, если добавлено свидетельство о рождении | Строка | От 1 до 255 символов |
| Дата выдачи свидетельства | Условно да, если добавлено свидетельство о рождении | Дата | Формат: DD.MM.YYYY Не может быть в будущем и не ранее 01.01.1926 |
| БИК | Да | Строка | 9 цифр. Должно начинаться с 0 |
| Наименование банка | Да | Строка | От 1 до 255 символов |
| Расчетный счет | Да | Целое число | 20 цифр |
